Simple Calculator in Java

Project Description

This project is a simple console-based calculator developed using Java for the CodeOrbit Tech internship.

Features

- Addition
- Subtraction
- Multiplication
- Division
- Handles division by zero
- Accepts user input

Technologies Used

- Java
- Eclipse IDE

How to Run

1. Open the project in Eclipse IDE.
2. Run the "SimpleCalculator.java" file.
3. Enter two numbers.
4. Select an operator (+, -, *, /).
5. View the result in the console.
